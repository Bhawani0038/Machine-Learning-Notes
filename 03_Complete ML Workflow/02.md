## 7\. Feature Engineering

**Definition\:** Feature engineering is the process of creating, transforming, or modifying input features to improve a Machine Learning model's performance.

**Common techniques\:**

- **Creating features\:** Derive new variables from existing columns.
- **Encoding\:** Convert categorical data into numerical representations.
- **Scaling\:** Bring numerical features to comparable scales.
- **Date and time extraction\:** Extract year, month, day, or hour.
- **Binning\:** Convert continuous values into groups.
- **Text transformation\:** Convert text into numerical features.

**Example\:** Suppose a loan dataset contains `annual_income` and `loan_amount`\.

We can create a new feature called `loan_to_income_ratio`\.

$$
\text{Loan-to-Income Ratio}=
\frac{\text{Loan Amount}}{\text{Annual Income}}
$$

```python
df["loan_to_income_ratio"] = (
    df["loan_amount"] / df["annual_income"]
)
```

If the loan amount is ₹500,000 and annual income is ₹1,000,000, the ratio is `0.5`\.

**Why is feature engineering important?**

- Helps models identify useful patterns.
- Represents business knowledge in the data.
- Can improve predictive performance.
- Makes raw data more suitable for algorithms.

**Important\:** Any learned transformation must be fitted using training data only, not the entire dataset.

## 8\. Feature Selection

**Definition\:** Feature selection is the process of selecting the most useful existing features for training a Machine Learning model.

Feature engineering creates or transforms features; feature selection chooses which features to retain.

**Common techniques\:**

| Technique | Explanation |
|--------|--------|
| Correlation analysis | Identifies strongly related numerical variables |
| Filter methods | Select features using statistical measures |
| Wrapper methods | Evaluate feature subsets using model performance |
| Embedded methods | Select features during model training |
| Domain knowledge | Select features based on subject expertise |

**Example\:**

Suppose the dataset contains\:

`age`, `cibil_score`, `annual_income`, `customer_name`, `application_id`\.

For loan approval prediction, `cibil_score` and `annual_income` may be useful predictors. `customer_name` and `application_id` may not provide meaningful predictive information.

```python
features = [
    "age",
    "cibil_score",
    "annual_income"
]

X = df[features]
y = df["loan_approved"]
```

**Benefits\:**

- Reduces unnecessary complexity.
- May reduce overfitting.
- Can improve interpretability.
- May reduce training time.

**Important\:** Do not select features using the test set. Also, do not automatically remove every highly correlated feature; their usefulness depends on the model and business context.

## 9\. Train-Test Split

**Definition\:** Train-test split divides a dataset into separate subsets so we can train a model and evaluate its performance on unseen data.

- **Training set\:** Used to learn model parameters.
- **Test set\:** Used for final evaluation on unseen observations.
- **Validation set\:** Used to compare models or tune settings, when a separate validation set is needed.

**Common split ratios\:**

| Training | Testing | Typical Use |
|--------|--------|--------|
| 80% | 20% | Common default |
| 70% | 30% | More test observations |
| 90% | 10% | Larger datasets, when appropriate |

**Python example\:**

```python
from sklearn.model_selection import train_test_split

X = df.drop(columns=["loan_approved"])
y = df["loan_approved"]

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.20,
    random_state=42,
    stratify=y
)
```

**Explanation\:**

- `test_size=0.20`\: Reserves 20% of the observations for testing.
- `random_state=42`\: Makes the random split reproducible.
- `stratify=y`\: Preserves approximately the same target-class proportions in both subsets.

**Important\:**

- For classification, stratification is often useful.
- For time-series data, use a chronological split rather than randomly mixing past and future observations.
- Perform data-dependent preprocessing after splitting to avoid leakage.

## 10\. Model Selection

**Definition\:** Model selection is the process of choosing an appropriate Machine Learning algorithm for a problem.

The choice depends on the problem type, dataset size, feature characteristics, interpretability requirements, and business constraints.

| Algorithm | Suitable Task | Example |
|--------|--------|--------|
| Linear Regression | Regression | Predict house prices |
| Logistic Regression | Classification | Predict loan default |
| Decision Tree | Classification/Regression | Loan risk prediction |
| Random Forest | Classification/Regression | Customer churn prediction |
| K-Nearest Neighbors | Classification/Regression | Similar-customer prediction |
| Support Vector Machine | Classification/Regression | Document classification |
| K-Means | Clustering | Customer segmentation |

**Example\:** To predict whether a loan applicant will default, we might compare Logistic Regression, Decision Tree, and Random Forest.

**Best practice\:** Begin with a simple baseline model, then compare more complex alternatives using the same evaluation procedure.

## 11\. Model Training

**Definition\:** Model training is the process in which an algorithm learns patterns from training data by estimating its parameters.

For example, Linear Regression learns coefficients and an intercept to minimize prediction errors.

$$
\hat{y} = b_0+b_1x_1+b_2x_2+\cdots+b_nx_n
$$

Where\:

- $\hat{y}$\: Predicted output
- $b_0$\: Intercept
- $b_1,\ldots,b_n$\: Learned coefficients
- $x_1,\ldots,x_n$\: Input features

**Python example\:**

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(max_iter=1000)

model.fit(X_train, y_train)
```

**What happens during training?**

1. The model receives training features and target values.
2. The algorithm estimates its parameters.
3. A learning objective or loss function guides parameter estimation.
4. The trained model can generate predictions for new inputs.

**Important distinction\:** Training learns model parameters. Hyperparameter tuning selects settings that control how the model is trained.

## 12\. Prediction

**Definition\:** Prediction is the process of using a trained model to estimate outcomes for new or existing observations.

In scikit-learn\:

- `predict()` returns predicted class labels or numerical values.
- `predict_proba()` returns class probabilities for supported classifiers.

**Example\:**

```python
y_pred = model.predict(X_test)

print(y_pred)
```

For a classification problem\:

```python
probabilities = model.predict_proba(X_test)

print(probabilities[:5])
```

Suppose a binary classifier returns\:

| Predicted Probability of Default | Predicted Class at Threshold 0.5 |
|--------|--------|
| 0.20 | No default |
| 0.45 | No default |
| 0.70 | Default |
| 0.90 | Default |

The threshold determines how probabilities are converted into class labels. It can be adjusted according to business costs and validation results.

**Important\:** Predicted probabilities are not automatically well-calibrated probabilities of real-world outcomes.
