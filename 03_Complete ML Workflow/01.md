# Module 3 - Complete Machine Learning Workflow

## 1\. Problem Definition

**Definition\:** Problem definition is the process of identifying exactly what we want to predict or solve using Machine Learning.

- Identify the problem to be solved.
- Determine the target variable.
- Identify the type of ML task.
- Define the expected output.

**Types of ML problems**

| Problem Type | Example | Algorithm |
|--------|--------|--------|
| Classification | Predict whether a customer will default | Logistic Regression |
| Regression | Predict house prices | Linear Regression |
| Clustering | Group customers by behavior | K-Means |
| Anomaly Detection | Detect unusual transactions | Isolation Forest |

**Example\:** A company wants to predict whether a loan applicant will repay a loan.

- Input: CIBIL score, annual income, existing loans.
- Target: `loan_approved`
- Problem type: Classification.

## 2\. Business Understanding

**Definition\:** Business understanding means understanding the business objective, requirements, constraints, and expected benefits before building a model.

- Understand the business requirements.
- Identify stakeholders and users.
- Define success criteria.
- Identify business constraints.
- Estimate the cost of incorrect predictions.

**Example\:** A bank wants to reduce loan defaults.

Business objective: Identify high-risk loan applicants before approving loans.

Possible success criteria\:

- Reduce default losses.
- Maintain an acceptable loan approval rate.
- Evaluate false approvals and false rejections.

**Important\:** A model with high accuracy is not necessarily a good business solution. The cost of its mistakes also matters.

## 3\. Data Collection

**Definition\:** Data collection is the process of gathering relevant data from different sources for Machine Learning.

**Common data sources\:**

- CSV and Excel files
- SQL databases
- APIs
- Websites and logs
- Sensors and IoT devices
- Cloud storage
- Existing business applications

**Example\:**

A bank collects historical loan application data containing\:

`age`, `cibil_score`, `annual_income`, `loan_amount`, `existing_loans`, `loan_approved`\.

**Important considerations\:**

- Data relevance
- Data quality
- Data quantity
- Data privacy and permissions
- Data representativeness
- Target availability

## 4\. Data Understanding

**Definition\:** Data understanding means examining the collected data to understand its structure, features, quality, and meaning.

**Common activities\:**

- Check the number of rows and columns.
- Identify numerical and categorical features.
- Inspect data types.
- Check missing values and duplicates.
- Examine unique values.
- Calculate descriptive statistics.
- Identify possible data leakage.

**Python example\:**

```python
import pandas as pd

df = pd.read_csv("loan_data.csv")

print(df.head())
print(df.shape)
print(df.info())
print(df.describe())
print(df.isnull().sum())
print(df.duplicated().sum())
```

**Important\:** Data understanding helps determine whether the available data is suitable for solving the problem.

## 5\. Data Cleaning

**Definition\:** Data cleaning is the process of identifying and correcting data quality problems.

| Problem | Possible Solution |
|--------|--------|
| Missing numerical values | Mean or median imputation |
| Missing categorical values | Most frequent value or a meaningful category |
| Duplicate records | Remove or investigate duplicates |
| Incorrect data types | Convert to appropriate types |
| Inconsistent categories | Standardize category names |
| Invalid values | Validate and correct using domain rules |
| Extreme values | Investigate and treat when justified |

**Example\:**

A dataset contains a missing `age` value.

```python
df["age"] = df["age"].fillna(df["age"].median())
```

**Important ML practice\:** When evaluating a model, learn imputation values from the training data only. Applying statistics calculated from the complete dataset can cause data leakage.

## 6\. Exploratory Data Analysis (EDA)

**Definition\:** EDA is the process of exploring data using statistical summaries and visualizations to discover patterns, relationships, and unusual observations.

**Common techniques\:**

- Histogram: Understand distributions.
- Box plot: Identify potential outliers.
- Bar chart: Compare categories.
- Scatter plot: Examine relationships between numerical variables.
- Correlation matrix: Examine linear relationships.
- Grouped summaries: Compare target outcomes across groups.

**Python example\:**

```python
import matplotlib.pyplot as plt
import seaborn as sns

sns.histplot(data=df, x="annual_income", kde=True)
plt.show()

sns.boxplot(data=df, x="loan_approved", y="cibil_score")
plt.show()

sns.heatmap(
    df.select_dtypes("number").corr(),
    annot=True,
    cmap="coolwarm"
)
plt.show()
```

**Important\:** Correlation does not establish causation. EDA findings should guide investigation rather than automatically determine which features cause an outcome.
